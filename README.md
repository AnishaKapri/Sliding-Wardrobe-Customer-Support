# Sliding Wardrobe Customer Support Chatbot

## Project Overview

The Sliding Wardrobe Customer Support Chatbot is a simple web-based application designed to answer common customer questions about sliding wardrobes.

It provides predefined responses to questions about pricing, delivery, installation, customization, and wardrobe care.

## Features

- Interactive chat interface
- Predefined customer support responses
- Keyword-based question matching
- Quick-question buttons for common enquiries
- Message timestamps
- Typing indicator
- Clear Chat functionality
- Input validation for empty and overly long messages
- Responsive layout for smaller screens

## Technologies Used

- **HTML5** — structures the chatbot interface
- **CSS3** — styles the chat window and makes the layout responsive
- **JavaScript** — handles user input, matches keywords, and displays responses

## How It Works

1. The customer types a question or selects a quick-question button.
2. JavaScript checks the message for supported keywords.
3. The chatbot selects a predefined response.
4. The response appears in the conversation window.

## How to Run the Project

1. Download or clone the project files.
2. Keep `index.html`, `style.css`, `script.js`, and `README.md` in the same project folder.
3. Open `index.html` in a web browser.
4. Start asking questions using the chat input or quick-question buttons.

## Current Limitations

- The chatbot uses predefined responses and keyword matching.
- It does not currently use a live AI model or connect to a company database.
- It cannot confirm actual prices, delivery dates, installation availability, or warranty policies.
- Questions it does not recognize receive a general fallback response.

## Future Improvements

- Integrate an AI model through a secure backend.
- Add verified company FAQs and product information.
- Connect to a customer enquiry or lead-management system.
- Improve question matching and error handling.
- Add options for customers to request a quotation or contact a human support representative.

## Learning Outcomes

This project demonstrates basic web development, JavaScript event handling, conditional logic, DOM manipulation, input validation, and chatbot interface design.
